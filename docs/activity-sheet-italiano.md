# FOGLIO DI ATTIVITÀ ITALIANO — LEVELINO / Tedesco per bambini (italiano-italiano)

_Foglio di esercizi stampabile per rafforzare il vocabolario tedesco attraverso attività ludiche. Per bambini dai 3 ai 9 anni. Compila il foglio, colora le caselle e guadagna un premio!_

---

## 📋 Panoramica

**Scopo:** Rafforzare il vocabolario tedesco imparato su LEVELINO con pratica offline
**Formato:** DIN A4, adatto alla stampa
**Sezioni per foglio:** 3 attività + 1 area premio
**Lingua:** Istruzioni in italiano, vocabolario tedesco da imparare

---

## 🎯 Attività 1: Parole (Word Matching)

**Tema:** Abbina l'immagine alla parola tedesca
**Età:** 3–6 anni

```
┌──────────────────────────────────────────────────────────────┐
│  ✓ MARCA    ┌─────────┐    ┌─────────┐    ┌─────────┐       │
│             │  🐕     │    │  🐱     │    │  🐦     │       │
│             │  HUND   │    │  KATZE  │    │  VOGEL  │       │
│             └─────────┘    └─────────┘    └─────────┘       │
│                                                              │
│  Scrivi le lettere mancanti:                                 │
│                                                              │
│  H__D   K___E   V__G_L                                      │
└──────────────────────────────────────────────────────────────┘
```

**Soluzioni (per genitori/insegnanti):** HUND, KATZE, VOGEL

### 🎨 Tema 1: Colori e Numeri (Farben & Zahlen)

**Età:** 3–6 anni

```
┌──────────────────────────────────────────────────────────────┐
│  Colora e impara i numeri:                                   │
│                                                              │
│   🔴🔴🔴🔴🔴        →   ____  (fünf = cinque)             │
│   🔵🔵🔵            →   ____  (drei = tre)                 │
│   🟢🟢🟢🟢           →   ____  (vier = quattro)             │
│   🟡🟡🟡🟡🟡🟡          →   ____  (sechs = sei)              │
│                                                              │
│  I colori: rot = rosso, blau = blu, grün = verde            │
│            gelb = giallo, weiß = bianco, schwarz = nero    │
└──────────────────────────────────────────────────────────────┘
```
