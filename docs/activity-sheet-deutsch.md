# LEVELINO Arbeitsblatt — Deutsch — Ausdruckbare Vokabelübungen

_Ein ausdruckbares deutsches Vokabelübungsblatt für Kinder (3–9 Jahre). Entwickelt, um das LEVELINO-Spiel zu Hause oder im Unterricht zu vertiefen._

---

## 📋 Überblick

**Zweck:** Vokabeln aus LEVELINO durch Offline-Übungen verstärken
**Format:** DIN A4, druckfreundlich
**Abschnitte pro Blatt:** 3 Aktivitäten + 1 Belohnungsbereich
**Sprache:** Deutsche Wörter mit deutschen Anweisungen

---

## 🎯 Aktivität 1: Wort-Matching (Word Matching)

**Thema:** Bild zum deutschen Wort zuordnen
**Altersgruppe:** 3–6 Jahre

```
┌──────────────────────────────────────────────────────────────┐
│  ✓ MARKE    ┌─────────┐    ┌─────────┐    ┌─────────┐       │
│             │  🐕     │    │  🐱     │    │  🐦     │       │
│             │  HUND   │    │  KATZE  │    │  VOGEL  │       │
│             └─────────┘    └─────────┘    └─────────┘       │
│                                                              │
│  Schreibe die richtigen Buchstaben:                          │
│                                                              │
│  H__D   K___E   V__G_L                                      │
└──────────────────────────────────────────────────────────────┘
```

**Lösungen (für Lehrer/Eltern):** HUND, KATZE, VOGEL

## 📝 Hinweise für Eltern und Lehrer

- **Drucken:** 90g/m² Papier verwenden, Farbe oder S/W
- **Hilfe:** Kinder von 3–5 Jahren brauchen vielleicht Hilfe beim Lesen
- **Erweiterung:** Lass das Kind jedes Wort laut aussprechen, bevor es malt
- **LEVELINO-Verbindung:** Ein vollständiges Blatt bringt einen Bonus-Gegenstand in der App!
