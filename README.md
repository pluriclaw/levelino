# LEVELINO

**German vocabulary learning game for mobile (iOS & Android).**

LEVELINO turns vocabulary and grammar into a mobile game adventure. No flashcards. No drills. No boring textbooks — just colorful levels, real progression, and that "one more round" feeling that makes learning feel like play.

---

## What It Is

A 30-level German language game covering greetings, colors, numbers, family, food, travel, grammar tenses, and idioms. Each session is 8–25 minutes, designed to fit a commute or coffee break. Adaptive difficulty keeps learners in the sweet spot — challenged, not overwhelmed.

---

## Project Contents

- `activity_sheets.csv` — Game data: levels, topics, scores, and stars earned
- `docs/` — Activity sheet templates and teacher notes
- `marketing/` — Positioning copy for newsletters, Product Hunt, Twitter/X threads

## Quick Start

Players progress through 30 themed levels over ~15 days, earning stars and coins along the way. The game tracks streaks and session scores to build a consistent learning habit.

**Available on iOS & Android.**
